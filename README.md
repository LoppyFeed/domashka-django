# Учебный блог на Django

Проект создан для практических заданий по курсу: маршруты, шаблоны, статика, модели и формы.

## Установка
1. Установите Python 3.12+.
2. Клонируйте репозиторий и перейдите в каталог проекта.
3. Создайте виртуальное окружение и активируйте его:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Выполните миграции и создайте администратора для модерации отзывов:
   ```bash
   python manage.py migrate
   python manage.py createsuperuser
   ```

## Запуск сервера
```bash
python manage.py runserver
```

Откройте в браузере `http://127.0.0.1:8000/`.

## Страницы
- `/` — главная с карточками постов.
- `/about/` — информация о блоге.
- `/posts/<slug>/` — страница поста с текстом.
- `/reviews/` — гостевая книга с формой и списком подтверждённых отзывов.
- `/admin/` — панель администратора для проверки отзывов (поле «is_verified»).

Статика лежит в `static/`, шаблоны — в `templates/`.
