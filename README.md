# Учебный блог на Django

Учебный проект для практики по курсу: маршруты, шаблоны, статика, модели и формы. Собирает в себе все этапы: старт проекта, шаблоны блога и гостевую книгу с модерацией.

## Требования
- Установлены Python (3.10+), Git и среда разработки (например, PyCharm).
- Доступ в интернет для установки зависимостей.

## Установка и запуск с нуля
1. Склонируйте публичный репозиторий и перейдите в каталог проекта:
   ```bash
   git clone <url-репозитория>
   cd domashka-django
   ```
2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv .venv
   source .venv/bin/activate      # Windows: .venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Выполните миграции базы данных и создайте администратора (нужен для подтверждения отзывов):
   ```bash
   python manage.py migrate
   python manage.py createsuperuser
   ```
5. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```
   Откройте в браузере `http://127.0.0.1:8000/`.

## Основные страницы
- `/` — главная с карточками постов.
- `/about/` — информация о блоге и структуре проекта.
- `/posts/<slug>/` — страница выбранного поста.
- `/reviews/` — гостевая книга: форма отправки и список подтверждённых отзывов.
- `/admin/` — панель администратора; отметьте галочкой «is_verified» для публикации отзыва.

## Кратко о структуре
- `blog/urls.py` — маршруты для главной, «о блоге», поста и отзывов.
- `templates/` — базовый шаблон и шаблоны страниц (наследование подключено).
- `static/` — стили и изображения, подключаются через `{% templatetag openblock %} load static {% templatetag closeblock %}`.
- `blog/models.py` — модель отзыва с полями ФИО, email, текст, флаг проверки.
- `blog/forms.py` — форма добавления отзыва (валидация обязательных полей).
- `blog/admin.py` — регистрация модели в админке.
- `requirements.txt` — зафиксированные версии библиотек.
